## 2. What the Extension Does
The Extension retrieves pending approval information from Azure DevOps to help users view:
- Release approvals
- Pipeline approvals/checks

It also highlights approvals assigned to the currently signed-in Azure DevOps user.

## 3. Data We Access
The Extension may access the following information from Azure DevOps APIs:
- Organization and project metadata
- Approval records and status
- Approver display names and profile image URLs
- Current authenticated user identifier from Azure DevOps connection data

## 4. How Data Is Used
Data is used only to:
- Display approval information inside the extension popup
- Highlight approvals assigned to the current user
- Open related approval pages in Azure DevOps
- Copy approval URLs when requested by the user

## 5. Data Storage
- User configuration (`org`, `apiVersion`) is stored locally using browser extension storage.
- Approval data is processed in-memory for display.
- The Extension does not persist approval records to developer-controlled servers.

## 6. Data Sharing
- The Extension does not sell personal data.
- The Extension does not transmit approval data to third-party servers controlled by the developer.
- API requests are sent only to Azure DevOps endpoints configured for extension functionality.

## 7. Security
The Extension communicates with Azure DevOps over HTTPS and requests only permissions required for functionality.

## 8. User Controls
Users can:
- Change or remove organization/API settings from the extension Options page.
- Remove the extension at any time from the browser.
